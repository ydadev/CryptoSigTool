# CryptoSigTool

> [!IMPORTANT]
> CryptoSigTool предоставляется «как есть» как вспомогательный инструмент. Визуальный штамп носит информационный характер и сам по себе не является электронной подписью и не гарантирует юридическую значимость документа. Пользователь самостоятельно отвечает за действительность сертификатов, лицензии CryptoPro, выбранные параметры, независимую проверку результата и соблюдение требований законодательства и принимающей системы. Перед использованием ознакомьтесь с [полным дисклеймером](DISCLAIMER-RU.txt).

CryptoSigTool — Windows-приложение для работы с электронными подписями CMS/PKCS#7 через установленный CryptoPro CSP 5.

## Возможности

- обнаружение сертификатов в контейнерах CryptoPro и установка отсутствующих сертификатов в личное хранилище пользователя;
- просмотр и безопасное удаление выбранных сертификатов из личного хранилища текущего пользователя;
- подпись одного файла или всех файлов выбранной папки;
- выбор одного или двух сертификатов;
- отсоединённые подписи `.sig` и вложенные контейнеры `.p7s`;
- двоичный DER и текстовый Base64;
- алгоритмы ГОСТ Р 34.11-2012/34.10-2012 и другие алгоритмы, поддерживаемые CryptoPro;
- проверка подписей с подробными сведениями о подписантах, времени, алгоритмах и сертификатах;
- объединение двух отсоединённых подписей одного файла в единый контейнер с двумя подписантами;
- пакетная обработка каталогов;
- встроенное подписание PDF с полноэкранным просмотром, выбором области мышью и визуальным штампом 63-ФЗ;
- последовательное подписание PDF несколькими сторонами без повреждения предыдущих подписей;
- полностью векторные текст и рамка PDF-штампа без JPEG-артефактов, автоматический подбор размера шрифта по области штампа и четыре готовых варианта дизайна;
- компоновка чёрного штампа в стиле Acrobat: отдельная строка «Сертификат:», номер на следующей строке и увеличенные вертикальные отступы;
- собственный логотип в PDF-штампе, дата и время подписания;
- CAdES-T через выбранную службу TSP и CAdES-XLT1 при наличии совместимых компонентов CryptoPro CAdES/TSP/OCSP;
- обычный Windows-установщик с ярлыками и удалением через «Установленные приложения».

## Требования

- Windows 10 или Windows 11 x64;
- CryptoPro CSP 5;
- для подписания — сертификат с доступным закрытым ключом;
- для CAdES-T/XLT1 — доступная служба TSP и установленные совместимые компоненты CryptoPro CAdES/TSP/OCSP;
- для переносной framework-dependent сборки разработчика — .NET Desktop Runtime 8;
- готовый архив и установщик из Releases автономны и отдельно установленного .NET не требуют.

## Установка

Скачайте `CryptoSigTool-Setup-1.8.0.exe` со страницы Releases и запустите его. Перед установкой будет показан дисклеймер. Установщик запросит права администратора и по умолчанию установит программу для всех пользователей в:

```text
%ProgramFiles%\CryptoSigTool
```

Установщик создаёт общий ярлык в меню «Пуск» и, по выбору, на общем рабочем столе всех пользователей. Удаление доступно через «Параметры → Приложения → Установленные приложения → CryptoSigTool» и также запрашивает права администратора.

Установщик пока не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 с файлом `SHA256SUMS.txt` в релизе.

Для передачи одним файлом используйте `CryptoSigTool-1.8.0-Release.zip`: внутри находятся установщик, переносная версия, инструкция, дисклеймер, описание релиза и контрольные суммы.

## Быстрый старт

Порядок вкладок соответствует обычному рабочему процессу:

1. **Добавить сертификат** — подключить носитель, найти сертификаты внутри контейнеров CryptoPro и установить отсутствующие в `CurrentUser\My`.
2. **Удалить сертификаты** — просмотреть `CurrentUser\My`, отметить сертификаты и удалить их после подтверждения.
3. **Подписать** — выбрать файл или папку, сертификат, алгоритм, тип и формат подписи.
4. **Проверить** — проверить контейнер CryptoPro и просмотреть подписантов, время, алгоритмы и сертификаты.
5. **Объединить .sig** — объединить две действительные отсоединённые подписи одного исходного файла.
6. **PDF 63-ФЗ** — открыть PDF, выбрать страницу и область штампа, сертификат, дизайн, логотип и при необходимости службу TSP, затем создать встроенную PDF-подпись.
7. **Дисклеймер** — ознакомиться с назначением программы, ограничениями ответственности и рекомендацией независимо проверять созданные подписи.

Визуальный штамп сам по себе не является электронной подписью. CryptoSigTool одновременно создаёт внутри PDF криптографическую CMS/CAdES-подпись и проверяет её перед выдачей результата. Начиная с версии 1.6 следующая подпись добавляется как новая инкрементальная редакция: байты предыдущей редакции не изменяются, поэтому документ можно последовательно подписывать с двух и более сторон. После операции программа проверяет все встроенные подписи.

Подробности: [руководство пользователя](docs/USER_GUIDE.md) и [инструкция по установке](docs/INSTALLATION.md).

## Безопасность

- PIN-код обрабатывается средствами CryptoPro и не сохраняется CryptoSigTool.
- Сертификаты устанавливаются только в личное хранилище текущего пользователя.
- При объединении исходные `SignerInfo` копируются без изменения, после чего итог проверяется CryptoPro.
- Программа не обходит запрет экспорта закрытых ключей и не извлекает неэкспортируемые ключи с аппаратных носителей.

Подробнее: [SECURITY.md](SECURITY.md).

## Сборка

Для локальной сборки требуется .NET SDK 8 или новее:

```powershell
dotnet build .\CryptoSigTool\CryptoSigTool.csproj -c Release
```

Для полного автономного релиза также требуется Inno Setup 6. Установщик сжимает встроенную среду .NET и не требует её отдельной установки на целевом компьютере:

```powershell
.\build-release.ps1 -Version 1.8.0
```

Артефакты появятся в `dist/`. Подробности: [docs/BUILDING.md](docs/BUILDING.md).
