# CryptoSigTool

CryptoSigTool — Windows-приложение для работы с электронными подписями CMS/PKCS#7 через установленный CryptoPro CSP 5.

## Возможности

- обнаружение сертификатов в контейнерах CryptoPro и установка отсутствующих сертификатов в личное хранилище пользователя;
- подпись одного файла или всех файлов выбранной папки;
- выбор одного или двух сертификатов;
- отсоединённые подписи `.sig` и вложенные контейнеры `.p7s`;
- двоичный DER и текстовый Base64;
- алгоритмы ГОСТ Р 34.11-2012/34.10-2012 и другие алгоритмы, поддерживаемые CryptoPro;
- проверка подписей с подробными сведениями о подписантах, времени, алгоритмах и сертификатах;
- объединение двух отсоединённых подписей одного файла в единый контейнер с двумя подписантами;
- пакетная обработка каталогов;
- обычный Windows-установщик с ярлыками и удалением через «Установленные приложения».

## Требования

- Windows 10 или Windows 11 x64;
- CryptoPro CSP 5;
- для подписания — сертификат с доступным закрытым ключом;
- для переносной framework-dependent сборки разработчика — .NET Desktop Runtime 8;
- готовый архив и установщик из Releases автономны и отдельно установленного .NET не требуют.

## Установка

Скачайте `CryptoSigTool-Setup-1.4.0.exe` со страницы Releases и запустите его. Установщик запросит права администратора и по умолчанию установит программу для всех пользователей в:

```text
%ProgramFiles%\CryptoSigTool
```

Установщик создаёт общий ярлык в меню «Пуск» и, по выбору, на общем рабочем столе всех пользователей. Удаление доступно через «Параметры → Приложения → Установленные приложения → CryptoSigTool» и также запрашивает права администратора.

Установщик пока не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 с файлом `SHA256SUMS.txt` в релизе.

## Быстрый старт

Порядок вкладок соответствует обычному рабочему процессу:

1. **Добавить сертификат** — подключить носитель, найти сертификаты внутри контейнеров CryptoPro и установить отсутствующие в `CurrentUser\My`.
2. **Подписать** — выбрать файл или папку, сертификат, алгоритм, тип и формат подписи.
3. **Проверить** — проверить контейнер CryptoPro и просмотреть подписантов, время, алгоритмы и сертификаты.
4. **Объединить .sig** — объединить две действительные отсоединённые подписи одного исходного файла.

Подробности: [руководство пользователя](docs/USER_GUIDE.md) и [инструкция по установке](docs/INSTALLATION.md).

## Безопасность

- PIN-код обрабатывается средствами CryptoPro и не сохраняется CryptoSigTool.
- Сертификаты устанавливаются только в личное хранилище текущего пользователя.
- При объединении исходные `SignerInfo` копируются без изменения, после чего итог проверяется CryptoPro.
- Программа не обходит запрет экспорта закрытых ключей и не извлекает неэкспортируемые ключи с аппаратных носителей.

Подробнее: [SECURITY.md](SECURITY.md).

## Сборка

Для локальной сборки требуется .NET SDK 8 или новее:

```powershell
dotnet build .\CryptoSigTool\CryptoSigTool.csproj -c Release
```

Полный автономный релиз и установщик:

```powershell
.\build-release.ps1 -Version 1.4.0
```

Артефакты появятся в `dist/`. Подробности: [docs/BUILDING.md](docs/BUILDING.md).
