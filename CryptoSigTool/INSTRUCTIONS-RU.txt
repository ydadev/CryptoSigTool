CRYPTOSIGTOOL — КРАТКАЯ ИНСТРУКЦИЯ

ВАЖНО: программа предоставляется «как есть». Визуальный штамп носит информационный
характер и сам по себе не является электронной подписью. Перед работой ознакомьтесь с
файлом DISCLAIMER-RU.txt и последней вкладкой «Дисклеймер», а созданные подписи
независимо проверяйте средствами CryptoPro или другим доверенным средством.

Требования:
• Windows 10/11 x64.
• Установленный CryptoPro CSP 5.
• Для подписания сертификат с закрытым ключом должен быть доступен в хранилище Windows.

1. ДОБАВИТЬ СЕРТИФИКАТ

Подключите носитель с ЭЦП и откройте вкладку «Добавить сертификат».
Программа покажет сертификаты, которые находятся в контейнерах CryptoPro, но отсутствуют
в личном хранилище текущего пользователя. Отметьте нужные сертификаты и нажмите
«Добавить выбранные».

Установка выполняется только в CurrentUser\My и не копирует закрытые ключи. Если список
пуст, все обнаруженные сертификаты уже установлены либо в контейнере отсутствует
встроенный сертификат, который можно установить.

2. УДАЛИТЬ СЕРТИФИКАТЫ

Откройте вкладку «Удалить сертификаты». В ней показаны все сертификаты из CurrentUser\My.
Действующие сертификаты отображаются чёрным и имеют статус «Действующая». Истёкшие и
ещё не действующие отображаются красным. Отметьте сертификаты и нажмите «Удалить выбранные».
Подтвердите действие в окне «Вы уверены?». Закрытые ключи и контейнеры CryptoPro не удаляются.

3. ПОДПИСАТЬ ФАЙЛ ИЛИ ПАПКУ

Откройте вкладку «Подписать».
Выберите один файл либо папку. Для папки можно включить вложенные каталоги.
Укажите отдельную папку результата.
Отметьте один или два сертификата с закрытым ключом.
Выберите алгоритм, тип подписи и формат контейнера.
Нажмите «Подписать и проверить».

Рекомендуемые параметры для российских квалифицированных сертификатов:
• алгоритм GOST12_256;
• отсоединённая подпись .sig;
• двоичный формат DER.

PIN-код запрашивает CryptoPro. CryptoSigTool его не читает и не сохраняет.
Если выбраны два сертификата, оба закрытых ключа должны быть доступны на компьютере.

4. ПРОВЕРИТЬ ПОДПИСЬ

Для отсоединённой подписи выберите исходный файл и .sig.
Для вложенной CMS/PKCS#7 выберите только .p7s, оставив поле исходного файла пустым.

После успешной проверки программа показывает для каждого подписанта ФИО и организацию,
заявленное время подписания, время штампа УЦ (если он присутствует), алгоритмы хеша и
подписи, хеш содержимого, сведения об издателе, серийный номер, отпечаток и срок действия
сертификата. Отчёт можно скопировать кнопкой «Скопировать данные».

5. ОБЪЕДИНИТЬ ДВЕ ПОДПИСИ

Откройте вкладку «Объединить .sig».
Выберите исходный файл, первую и вторую отсоединённые подписи.
Укажите имя итогового .sig и нажмите «Объединить и проверить».

Программа проверяет обе исходные подписи через CryptoPro, объединяет их без изменения
SignerInfo, затем проверяет итоговый контейнер. При несовпадении исходного файла операция
прекращается.

6. ДОБАВИТЬ СВОЮ ПОДПИСЬ В ПОЛУЧЕННЫЙ .SIG

Откройте вкладку «Добавить», выберите полученный PDF и присланный отсоединённый .sig.
Выберите свой сертификат, алгоритм и формат результата, затем нажмите «Подписать и
добавить в .sig». Программа проверит присланную подпись на выбранном PDF, создаст и
проверит вашу подпись, объединит их и проверит общий контейнер. Исходные PDF и .sig не
изменяются.

7. ПОДПИСАТЬ PDF СО ШТАМПОМ 63-ФЗ

Откройте вкладку «PDF 63-ФЗ» и выберите PDF. Перейдите на нужную страницу, настройте
масштаб и выделите мышью прямоугольную область штампа. Выберите сертификат, алгоритм,
один из четырёх готовых дизайнов и при необходимости логотип, причину и место подписания.
Флажок добавления даты и времени по умолчанию снят; включите его только при необходимости.

Текст и рамка штампа сохраняются векторными и не подвергаются JPEG-сжатию. Поэтому они
остаются резкими при увеличении. Растровым остаётся только логотип из файла JPEG/PNG.
Размер заголовка и служебных строк автоматически подстраивается по ширине и высоте
выделенной области, чтобы данные сертификата и дата подписания помещались без обрезания.

Базовая встроенная PDF-подпись работает через CryptoPro CSP без Adobe Acrobat. Для
доверенного времени включите CAdES-T и укажите службу TSP. Для доказательств подлинности
включите CAdES-XLT1. Эти режимы требуют компонентов CryptoPro CAdES/TSP/OCSP и доступа
к соответствующим службам.

Визуальный штамп не заменяет электронную подпись. Программа создаёт CMS/CAdES-подпись
внутри PDF и проверяет её перед сохранением. Уже подписанный PDF можно подписать второй
или следующей стороной: новая подпись добавляется без изменения предыдущей редакции,
после чего программа проверяет все встроенные подписи.

8. СОЗДАТЬ НЕПОДПИСАННУЮ КОПИЮ PDF

Откройте вкладку «Удалить подписи PDF», выберите подписанный документ и проверьте список
найденных полей подписи. Укажите путь новой копии с окончанием .unsigned.pdf, нажмите
«Создать неподписанную копию» и подтвердите действие. Программа удалит из новой копии
встроенные подписи и связанные с ними видимые штампы, затем проверит результат.

Исходный подписанный PDF не изменяется. Полученная копия не является побайтным
восстановлением первоначального оригинала. Обязательно сохраните подписанный исходник для
подтверждения истории документа. Изображения, вручную встроенные в обычное содержимое
страницы и не связанные с полем подписи, автоматически не удаляются.

ВАЖНО

«Вложенная CMS/PKCS#7» означает, что исходный файл находится внутри контейнера .p7s.
Это не видимая PDF-подпись и не подпись, встроенная в структуру самого PDF.

При пакетной подписи существующие результаты не перезаписываются: к новому имени
добавляется номер, например «документ.pdf (2).sig».
