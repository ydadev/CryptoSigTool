# CryptoSigTool 1.8.1 — 2026-08-14

Версия 1.8.1 добавляет безопасное создание неподписанной копии PDF для повторного подписания, когда первоначальный неподписанный файл недоступен.

## Новая вкладка «Удалить подписи PDF»

- показывает число страниц, количество встроенных подписей, имена полей и страницы с видимыми штампами;
- создаёт отдельный файл с окончанием `.unsigned.pdf`, не изменяя подписанный исходник;
- удаляет все встроенные поля электронной подписи и связанные с ними видимые штампы;
- удаляет разрешения подписи и сведения долгосрочной проверки, относящиеся к удалённым подписям;
- после сохранения повторно открывает результат и проверяет, что число страниц не изменилось и полей подписи не осталось;
- перед операцией показывает предупреждение, в котором по умолчанию выбрано «Нет».

## Важное ограничение

Результат является новой неподписанной редакцией PDF, а не побайтным восстановлением первоначального оригинала. Подписанный исходный файл следует сохранить для подтверждения истории документа. Обычные изображения или надписи, вручную встроенные в содержимое страницы и не связанные с полем подписи, автоматически не удаляются.

## Комплект релиза

- `CryptoSigTool-Setup-1.8.1.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.8.1-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.8.1-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы артефактов.

Для подписания и проверки требуется установленный CryptoPro CSP. Удаление встроенных подписей из PDF выполняется локально и не требует закрытого ключа.
