# CryptoSigTool 1.4.0 — 2026-08-13

Первый оформленный публичный выпуск CryptoSigTool — Windows-приложения для работы с электронными подписями CMS/PKCS#7 через CryptoPro CSP 5.

## Что входит

- добавление отсутствующих публичных сертификатов из контейнеров CryptoPro в личное хранилище пользователя;
- подпись файла или каталога одним/двумя сертификатами;
- отсоединённые `.sig` и вложенные `.p7s`, DER и Base64;
- подробная проверка подписантов, времени, алгоритмов и сертификатов;
- объединение двух действительных `.sig` одного файла;
- автономная переносная версия;
- системный Windows-установщик для всех пользователей с запросом UAC, общим меню «Пуск», опциональным общим ярлыком рабочего стола и удалением через «Установленные приложения».

## Файлы релиза

- `CryptoSigTool-Setup-1.4.0.exe` — рекомендуемый установщик для Windows x64;
- `CryptoSigTool-1.4.0-win-x64.zip` — переносная автономная версия;
- `SHA256SUMS.txt` — контрольные суммы SHA-256.

## Требования

Требуется установленный CryptoPro CSP 5. Готовые файлы релиза содержат .NET Runtime и не требуют отдельной установки .NET.

## Важно

Установщик пока не имеет цифровой подписи издателя, поэтому SmartScreen может показать предупреждение. Проверяйте SHA-256. CryptoSigTool не экспортирует и не копирует неэкспортируемые закрытые ключи.

## Проверено

- Windows x64;
- CryptoPro CSP 5;
- CMS/PKCS#7 с одним и двумя подписантами;
- отсоединённые и вложенные контейнеры;
- DER и Base64;
- системная установка и удаление для всех пользователей с запросом UAC.
