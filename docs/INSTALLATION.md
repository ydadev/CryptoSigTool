# Установка и удаление

## Установка

1. Убедитесь, что установлен CryptoPro CSP 5.
2. Скачайте `CryptoSigTool-Setup-1.4.0.exe` и `SHA256SUMS.txt` из одного релиза.
3. При необходимости проверьте контрольную сумму:

   ```powershell
   Get-FileHash .\CryptoSigTool-Setup-1.4.0.exe -Algorithm SHA256
   ```

4. Запустите установщик.
5. Выберите папку установки и необходимость ярлыка на рабочем столе.
6. Нажмите «Установить».

Установщик запрашивает права администратора, выполняет установку для всех пользователей и по умолчанию использует `%ProgramFiles%\CryptoSigTool`. Ярлыки создаются в общем меню «Пуск» и, если выбран соответствующий флажок, на общем рабочем столе.

## Обновление

Закройте CryptoSigTool и запустите установщик новой версии. Файлы программы будут обновлены, а запись в «Установленных приложениях» — заменена актуальной.

## Удаление

Откройте «Параметры → Приложения → Установленные приложения», найдите CryptoSigTool и нажмите «Удалить». Windows запросит права администратора. Также можно запустить `Uninstall.exe` из папки программы.

Удаляются файлы приложения, ярлыки и запись деинсталлятора. Сертификаты, контейнеры CryptoPro, исходные документы и созданные подписи не удаляются.

## Переносная версия

Распакуйте `CryptoSigTool-1.4.0-win-x64.zip` и запустите `CryptoSigTool.exe`. Переносная версия не регистрируется в Windows и удаляется удалением распакованной папки.
