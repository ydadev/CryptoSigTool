# Руководство пользователя

## Добавление сертификата

Подключите носитель и откройте первую вкладку. CryptoSigTool перечисляет контейнеры CryptoPro, извлекает их публичные сертификаты и сравнивает отпечатки с `CurrentUser\My`. Отметьте отсутствующие сертификаты и нажмите «Добавить выбранные».

Закрытый ключ остаётся на носителе. Если встроенного сертификата нет или он уже установлен, строка в списке не показывается.

## Подписание

Выберите один файл или папку. Для папки можно включить рекурсивную обработку. Затем:

- отметьте один или два сертификата;
- выберите алгоритм хеша;
- выберите отсоединённую `.sig` или вложенную CMS/PKCS#7 `.p7s`;
- выберите DER или Base64;
- укажите отдельную папку результата.

Рекомендуемый вариант для большинства российских квалифицированных сертификатов: `GOST12_256`, отсоединённая `.sig`, DER.

При двух сертификатах программа создаёт две подписи штатными средствами CryptoPro, объединяет их в один CMS-контейнер и проверяет результат.

## Проверка

Для `.sig` выберите исходный файл и подпись. Для вложенной `.p7s` поле исходного файла можно оставить пустым. После успешной проверки показываются:

- ФИО и организация подписанта;
- заявленное время `signingTime`;
- время штампа УЦ, если присутствует RFC 3161 token;
- алгоритмы хеша и подписи;
- хеш подписанного содержимого;
- субъект, издатель, серийный номер, отпечаток и срок сертификата.

Заявленное время подписания не равно криптографически подтверждённому времени. Подтверждённое время требует отдельного штампа службы доверенного времени.

## Объединение

Выберите исходный файл и две отсоединённые подписи. Каждая исходная подпись проверяется CryptoPro. Затем их сертификаты и `SignerInfo` объединяются в один контейнер, который снова проверяется CryptoPro.

Подписи должны относиться к одному и тому же байтовому содержимому. Простое склеивание файлов `.sig` недопустимо.

## Журнал

Нижняя часть окна содержит ход операции и сообщения CryptoPro. При ошибке сохраните текст журнала и укажите версию Windows, CryptoPro и CryptoSigTool.
