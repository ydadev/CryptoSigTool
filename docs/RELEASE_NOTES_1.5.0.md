# CryptoSigTool 1.5.0 — 2026-08-14

Выпуск добавляет встроенное подписание PDF с визуальным штампом электронной подписи без обязательной установки Adobe Acrobat и модуля «КриптоПро PDF».

## Новое

- полноэкранная вкладка «PDF 63-ФЗ»;
- просмотр PDF, переход между страницами, масштабирование и выбор области штампа мышью;
- встроенная CMS/CAdES-подпись PDF с закрытым ключом через CryptoPro CSP;
- штамп с номером и владельцем сертификата, сроком действия и датой подписания;
- добавление собственного логотипа JPEG/PNG;
- CAdES-T с настраиваемой службой TSP;
- CAdES-XLT1 с доказательствами подлинности при наличии CryptoPro CAdES/TSP/OCSP;
- автоматическая криптографическая проверка созданной PDF-подписи;
- PDFsharp 6.2.4 GDI по лицензии MIT.

## Требования и ограничения

- Windows 10/11 x64 и CryptoPro CSP 5;
- для CAdES-T/XLT1 нужны совместимые компоненты CryptoPro CAdES/TSP/OCSP, доступ к службам и необходимые лицензии поставщика;
- адрес TSP задаётся пользователем;
- версия 1.5 подписывает исходный неподписанный PDF; добавление второй подписи в уже подписанный PDF временно заблокировано для защиты существующей подписи;
- визуальный штамп является представлением, юридическую значимость обеспечивает встроенная криптографическая подпись;
- установщик пока не имеет подписи издателя и может вызвать предупреждение SmartScreen.

## Файлы релиза

- `CryptoSigTool-Setup-1.5.0.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.5.0-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.5.0-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы.
