# CryptoSigTool 1.5.1 — 2026-08-14

Исправляющий выпуск для встроенного подписания PDF.

## Исправлено

- устранена ошибка `Cannot seek in a RangedStream`, возникавшая после выбора области штампа и нажатия «Подписать PDF»;
- исправление действует для обычной подписи через CryptoPro CSP и для CAdES-T/CAdES-XLT1;
- добавлена автоматическая проверка того же типа потока, который PDFsharp передаёт модулю подписи.

## Требования и ограничения

- Windows 10/11 x64 и CryptoPro CSP 5;
- для CAdES-T/XLT1 нужны совместимые компоненты CryptoPro CAdES/TSP/OCSP, доступ к соответствующим службам и необходимые лицензии поставщика;
- адрес TSP задаётся пользователем;
- добавление второй подписи в уже подписанный PDF временно заблокировано для защиты существующей подписи;
- установщик пока не имеет подписи издателя и может вызвать предупреждение SmartScreen.

## Файлы релиза

- `CryptoSigTool-Setup-1.5.1.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.5.1-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.5.1-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы.
