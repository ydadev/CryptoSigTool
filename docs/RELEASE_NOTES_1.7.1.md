# CryptoSigTool 1.7.1 — 2026-08-14

Исправляющий выпуск для визуального штампа встроенной PDF-подписи.

## Что исправлено

- размер шрифта автоматически подбирается по ширине и высоте выделенной области;
- расчёт учитывает общую колонку названий полей и самое длинное значение сертификата;
- длинный серийный номер, владелец, срок действия и строка «Дата подписания» помещаются без обрезания при обычных размерах штампа;
- одинаковый алгоритм компоновки применяется к первой, второй и последующим подписям PDF;
- текст и рамка остаются векторными, без JPEG-сжатия и цветных артефактов.

## Проверено

- сборка проекта без предупреждений и ошибок;
- добавление второй подписи в реальный ранее подписанный PDF с сохранением байтового префикса первой редакции;
- наличие двух встроенных подписей после операции;
- отсутствие растрового изображения в штампе без пользовательского логотипа;
- визуальная проверка полного серийного номера и всех четырёх служебных строк.

## Файлы релиза

- `CryptoSigTool-Setup-1.7.1.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.7.1-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.7.1-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы SHA-256.

Установщик запрашивает права администратора, устанавливает программу для всех пользователей, создаёт общий ярлык меню «Пуск» и предлагает создать ярлык на общем рабочем столе.
