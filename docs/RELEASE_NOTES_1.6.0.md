# CryptoSigTool 1.6.0 — 2026-08-14

Выпуск добавляет штатное двухстороннее и последовательное подписание PDF.

## Добавлено

- уже подписанный PDF можно открыть на вкладке «PDF 63-ФЗ» и подписать другим сертификатом;
- каждая следующая подпись добавляется отдельной инкрементальной редакцией PDF;
- предыдущие байты документа не пересохраняются, поэтому существующие подписи сохраняют силу;
- после операции CryptoSigTool проверяет все встроенные подписи, а ГОСТ-подписи проверяет через установленный CryptoPro CSP;
- для последующих подписей доступны выбор области, штамп 63-ФЗ, логотип, дата, CAdES-T и CAdES-XLT1.

## Ограничения безопасности

Программа не обходит защиту PDF. Добавление подписи прекращается, если документ зашифрован, содержит ограничивающую политику DocMDP, usage rights или блокировку полей подписи.

## Проверено

- на реальном PDF с существующей подписью ГОСТ Р 34.10-2012/256 добавлена вторая тестовая подпись;
- обе криптографические подписи успешно проверены;
- исходный подписанный PDF полностью совпадает с байтовым префиксом результата;
- оба визуальных штампа корректно отображаются на странице.

## Файлы релиза

- `CryptoSigTool-Setup-1.6.0.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.6.0-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.6.0-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы.
