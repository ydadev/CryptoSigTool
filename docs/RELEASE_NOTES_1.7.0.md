# CryptoSigTool 1.7.0 — 2026-08-14

Выпуск улучшает внешний вид PDF-подписи и добавляет управление личным хранилищем сертификатов.

## Векторный штамп PDF

- текст, рамка и данные сертификата теперь записываются как настоящие векторные PDF-контуры;
- JPEG-сжатие штампа удалено, поэтому вокруг букв и линий больше нет цветных артефактов;
- штамп остаётся резким при любом масштабе и при печати;
- растровым остаётся только пользовательский логотип, если выбран исходный JPEG/PNG;
- векторный штамп работает как для первой, так и для второй и последующих подписей.

## Готовые дизайны

- «Чёрный со скруглением — как Acrobat» — выбран по умолчанию;
- «Зелёный — 63-ФЗ»;
- «Синий — официальный»;
- «Чёрный — минималистичный».

## Удаление сертификатов

- добавлена вкладка «Удалить сертификаты» для `CurrentUser\My`;
- действующие сертификаты показаны чёрным со статусом «Действующая»;
- истёкшие сертификаты и ещё не вступившие в силу показаны красным;
- поддерживаются флажки и удаление нескольких выбранных сертификатов;
- перед удалением обязательно показывается предупреждение «Вы уверены?» с ответом «Нет» по умолчанию;
- закрытые ключи и контейнеры CryptoPro не удаляются.

## Проверено

- все четыре дизайна добавлены в реальный ранее подписанный PDF;
- для каждого результата сохранён точный байтовый префикс первой подписи;
- обе встроенные подписи успешно прошли криптографическую проверку;
- в добавленной редакции отсутствует растровое изображение штампа;
- чтение и цветовая классификация сертификатов `CurrentUser\My` проверены без удаления пользовательских сертификатов.

## Файлы релиза

- `CryptoSigTool-Setup-1.7.0.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.7.0-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.7.0-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы.
