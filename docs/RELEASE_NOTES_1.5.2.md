# CryptoSigTool 1.5.2 — 2026-08-14

Исправляющий выпуск для контрольной проверки встроенных ГОСТ-подписей PDF.

## Исправлено

- устранена ошибка `Unknown algorithm '1.2.643.7.1.1.1.1'`, появлявшаяся после успешного подписания PDF сертификатом ГОСТ Р 34.10-2012/256;
- ГОСТ-подписи PDF теперь проверяются установленным CryptoPro CSP, а не стандартным модулем .NET, который может не распознавать российские алгоритмы;
- проверка по-прежнему выполняется до сообщения об успешном завершении операции.

## Проверено

- документ, созданный при пользовательском тестировании версии 1.5.1, успешно проверен через CryptoPro CSP;
- обнаружен один подписант;
- алгоритм хеширования: ГОСТ Р 34.11-2012, 256 бит (`1.2.643.7.1.1.2.2`).

- `CryptoSigTool-Setup-1.5.2.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.5.2-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.5.2-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы.
