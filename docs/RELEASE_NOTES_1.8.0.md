# CryptoSigTool 1.8.0 — 2026-08-14

Выпуск уточняет оформление PDF-штампа по образцу Adobe Acrobat и добавляет дисклеймер во все точки распространения программы.

## Штамп PDF

- флажок добавления даты и времени по умолчанию снят;
- в дизайне «Чёрный со скруглением — как Acrobat» заголовок и реквизиты расположены по пропорциям образца Acrobat;
- «Сертификат:» и серийный номер выводятся на отдельных строках;
- владелец и период действия выводятся отдельными строками без общей табличной колонки;
- увеличены вертикальный интервал между заголовком и реквизитами, внутренний отступ слева и свободное пространство снизу;
- сохранены автоматическая подгонка размера шрифта, векторный текст и векторная рамка без JPEG-сжатия;
- остальные три дизайна сохранили прежнюю компоновку.

## Дисклеймер

- добавлена последняя вкладка программы «Дисклеймер»;
- установщик показывает дисклеймер до начала установки;
- файл `DISCLAIMER-RU.txt` входит в установленную и переносную версии;
- краткое предупреждение размещено в самом начале README;
- руководство пользователя и инструкция по установке обновлены.

## Проверено

- дата и время выключены при первом запуске интерфейса;
- новая вкладка находится последней;
- первая и последующая инкрементальные PDF-подписи используют одинаковую новую компоновку;
- полный 40-символьный серийный номер помещается без обрезания;
- предыдущая подпись PDF и байтовый префикс документа сохраняются;
- проект собирается без предупреждений и ошибок.

## Файлы релиза

- `CryptoSigTool-Setup-1.8.0.exe` — системный установщик для всех пользователей;
- `CryptoSigTool-1.8.0-win-x64.zip` — автономная переносная версия;
- `CryptoSigTool-1.8.0-Release.zip` — полный комплект;
- `SHA256SUMS.txt` — контрольные суммы SHA-256.
